# 💖 Valentine's Day Game

A sweet and interactive Valentine's Day game built with HTML, CSS, and JavaScript!

## 🎮 How to Play

1. Click the **"Start"** button to begin
2. Click on the falling hearts ❤️ to collect them
3. Collect all 5 hearts to win
4. See the special message when you complete the game!

## ✨ Features

- 🎨 Beautiful gradient background and modern UI
- 💕 Interactive heart-clicking game mechanic
- ⏱️ Hearts appear and disappear with smooth animations
- 📱 Responsive design that works on mobile and desktop
- 💝 Personalized Valentine's message

## 📝 Customization

You can personalize the game by editing the HTML:

- **Change the name:** Replace `Hi Jashan` with your loved one's name
- **Add an image:** Replace `YOUR_IMAGE_HERE` with an image URL
- **Change the message:** Modify the text in the `<p>` tags
- **Customize colors:** Edit the color codes in the `<style>` section

## 🛠️ Technologies Used

- HTML5
- CSS3 (Gradients, Animations, Flexbox)
- Vanilla JavaScript
